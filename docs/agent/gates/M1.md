## What was built

- Repository layout, directional CMake targets, presets, and CI matrix.
- Copied `core` and optional `gpu` layers with 75 copied regression tests.
- Platform data directory, durable append/replace, sampling, and staged key-store backends.
- Cross-platform golden target using Monocypher 4.0.2 and immutable expected-hex fixtures.
- RFC 8032 Ed25519 vectors, BLAKE2b-256 known-answer vectors, float-free RFC 8785 canonicalization, and a signed project batch containing a >2^53 HLC, negative integer, UTF-8 French/Arabic text, quote, backslash, and escaped control character.
