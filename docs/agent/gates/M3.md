## What was built

- `src/log`: records and batches with float-free RFC 8785 canonicalization, exact int64 decimals (decision 0003), BLAKE2b hashing, monotonic HLC, segments with one durable write per batch and torn-tail cut, `NullSigner` (Ed25519 arrives in M4).
- `src/store`: the DESIGN schema plus `schema_version` and migrations, WAL, the subtree range query, typed statements, CSV export ≤ L9.
- `src/state`: the single state-writer thread — ATTEMPT group-commit with ≥ 1/s flush (decision 0000), terminal batches (children, CRITIQUE, ATOMIC, SETTLE last), the deterministic fold with highest-(hlc, origin) upserts, idempotent replay, campaign stop-is-final, TOMBSTONE and REVIEW folds, crash hooks at the commit steps.
- `src/gate`: fixed-instruction-first prompts, the ≤ 400-token pre-check, strict parsers, every deterministic check (count 3–100, repeats against node/ancestors/siblings/existing, style gates, parent ≥ 0.85 / ancestors ≥ 0.95), the best-of-3 `decide()` at temperatures 0/0.3/0.5 with injected issues, the funnel loop, the light funnel, the quality guard.
- `src/sched`: the campaign spec (decision 0008), ticket ordering (breadth/depth, ties by path, scope/settled/leaf/review exclusions, review pauses the subtree), the stop rule (last 50 ≥ 90% atomic, average ≥ 0.8), RESERVE chunks, G9 waiting reservations, review accept/retry/reject, self-closing finished campaigns, per-run call counts.
- `src/api` + `src/cli`: plain-HTTP server on 127.0.0.1 with token + Origin + Content-Type checks; `node run`, `campaign start/pause/resume/stop`, `review list/accept/retry/reject`, `dev-import`, `export-csv`; the dashboard at `/` reading `/api/state`.
- `tools/fake_deepseek`: the deterministic `--funnel` mode (depth-keyed replies, `--funnel-max-depth`, `--funnel-score`) that drives whole offline campaigns.
- Fixed an M2 client defect: the assistant `content` was regex-extracted and stopped at the first escaped quote, truncating every funnel reply; replaced with a nlohmann parse (all M2 client tests stay green).

## Deviations from DESIGN.md

- The engine treats a node as "atomic" for the stop rule when its `SETTLE` recorded at least one atomic child (decision 0008 §2).
- `NEEDS_REVIEW` payloads carry `attempts` and `score` in addition to `path, reason` (decision 0008 §3).
- The connect timeout (decision 0007) and the campaign-file format (decision 0008) extend the spec as recorded.

## Known issues and risks

- DeepSeek's automatic prompt cache did not engage for the M3 real campaign (0 cache-hit tokens), matching the M2 finding; the fixed-text-first layout is correct but the prefix may be too short to trigger the cache.
- Prices come from CLI flags for now; `node.conf` (M5) replaces them.
- The local API serves plain HTTP on 127.0.0.1 (no TLS by design — nothing leaves the loopback interface).
- Hosted CI has no real fp64 GPU (M1 carry-over).
