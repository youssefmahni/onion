## What was built

- `src/profile`: the hardware scan (OS, cores, RAM, disk, durable-write probe, OpenCL fp64, battery, link speed, provider round-trip), rules version 1 (desktop/laptop), `node.conf` overrides that always win, `MEMBER_PROFILE` versions with `prev`, `reason` and `changed` (a new version only on change), and the fold into the `profiles` table.
- `src/profile/service`: golden systemd unit (StateDirectory, Restart=always, no Environment secrets), launchd plist (KeepAlive) and the Windows Service registration script (sc.exe, restart-on-failure).
- Key stores: the macOS Keychain backend (via the OS `security` tool, fork/exec); Windows DPAPI was already staged in M1; the Linux 0600 file stays.
- CLI: `node profile` (scan + derived settings + stored version history), `node key set`, `node install-service`; `node run` feeds the profile's start limit / ceiling into the client concurrency.
- Records stay float-free: every profile measurement is an exact decimal string (decision 0003).
