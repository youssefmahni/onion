## Post-review fixes (owner 2026-10-13)

- **Push address recording**: the sync URL is stored only after the request signature verifies (the signed bytes bind the device id) AND only for a current member (row neither EVICTED nor LEFT, or static member); `SyncTest.PushAddressRecordingRequiresACurrentMemberSignature` (unsigned → 401, foreign key → 401, valid → recorded), decision 0018.
- **Chaos hooks behind `ONION_CHAOS_HOOKS`** (OFF in release presets, ON in test builds) + `m7.release_ignores_chaos_hooks` on hookless builds; the scenarios probe `node chaos-hooks` and skip (exit 77) on release binaries.
- **Scenario C implemented** (steal without duplicates — the docstring always listed it; the gate row previously cited only the unit test).
- **Lane-ownership root fix**: the live lane list now INCLUDES this device (it was excluded, so every device owned nothing and the fleet converged only through cross-stealing). Scenario C exposed it; with self in the list the fleet converges on own lanes first, stealing only when idle, per the DESIGN.
- **Replay nonce contract** recorded (decision 0018): ≥128-bit fresh nonce per request, retries sign fresh bytes; the macOS key-storage record (decision 0019): file-first, keychain migration fallback, fail-closed.
- **Decision 0014 amendment**: "completed sync round" = at least one peer answered within its 3 s/5 s timeouts; a slow or dead peer cannot stall reservations, a fully partitioned round unlocks nothing.
