# UI Guide — dashboard, TUI, native viewer, review tree

Four front-ends, all consuming the same `/api/state` (or the generated artifacts).

## 1. `dashboard.html` — "Mission Control" (three.js WebGL)

- **10 neon Saturn rings** — one `THREE.Points` vertex **per node** per layer (300k+ points, no cap; dots rebuilt only when a layer count changes; incremental-rotation layout).
- Starfield (2,500 points), `UnrealBloomPass` bloom, drag-to-rotate, wheel/pinch zoom (0.45–2.6×), hover tint, click → ring detail card tracking the ring's screen position; active-layer dots pulse while the funnel runs.
- Left cards: Machine Load sparkline (load/cpu/ram/net/threads); FUNNEL card (root/node/step/loop/queued/failures/completion bar/agent counters P/W/T/C/S with live running counts/last log line/funneled-kept-atomic-calls-retried-errors chips); Control card (state chip, Pause/Stop/Continue/Start, thread-cap slider + presets → `POST /api/threads`); Nodes card (per-node progress, stage chips, score/kept).
- **Policy engine:** loads `depot_core_wasm.js`; on success uses `wasm_policy_target` via `cwrap` and shows `policy engine: WASM (depot_core)`; identical JS fallback otherwise. Polls `/api/state` every 2 s.

## 2. `tui.py` — Textual terminal dashboard

- Auto-spawns the controller (`--no-spawn` to disable); `--seed --limit --port --url`; `ONION_TUI_URL`.
- Braille onion rings (one braille dot per node per layer, incremental rotation, wide-ellipse aspect fit, zoom 0.5–3.0, click-to-select).
- Gauges line (LOAD/CPU/RAM/NET/GPU/THREADS target+live/pid/status), 5 sparklines, FUNNEL + Nodes cards, Control card (Pause/Stop/Continue/Start + thread-cap Select: Auto/1/4/8/16/32/64/100/150/250/500/1000/2000/5000).
- Keys: `q p s t + - c 0-9`. Independent `policy_target` mirror for the recommendation line.

## 3. `onion_gl` — native OpenGL viewer

- C++17 + Xlib/GLX window (1280×800 default); same 10-layer geometry; stb_truetype glyph atlas; HUD with top bar, sparklines, funnel context, node list, layer card, cap preset cycling.
- Keys: `q p s t 0-9 c + - [ ]`; mouse click picks a ring, wheel zooms; vsync via `glXSwapIntervalEXT/MESA`.
- **`--term` mode** (needs EGL): offscreen render → `glReadPixels` → **sixel** (216-colour cube + 24-step gray, 6-row bands, RLE `!N`, tmux DCS passthrough, synchronized-update `?2026h`) with automatic fallback to truecolor **half-blocks** (`--term=blocks`); refuses piped/non-TTY runs; `SIGWINCH` resize; image sized from the terminal's real pixel area (`CSI 14 t`).
- Other flags: `--term-once`, `--term-size COLSxROWS`, `--term-scale/--scale 0.3–1.0`, `--font TTF`, `--width/--height`, `--no-spawn`, `--selftest` (headless), `--opt=value` everywhere; auto-spawns a local controller after 2 s on loopback.

## 4. `Onion_Review.html` — D3 collapsible tidy tree (generated by `gen_onion_html.py`)

- Inlined D3 v7 (`third_party/d3.v7.min.js`; CDN fallback); tidy-tree layout (`nodeSize([16, 240])`), horizontal links, zoom/fit.
- Scaled for 300k+ nodes:
  - **Lazy materialization** — children created only on expand.
  - **CHUNK = 2000** fan-out cap per node + "… N more" node loading the next chunk on click.
  - **LABEL_MAX = 300** — text labels only under this many visible nodes.
  - **SUBTREE_CAP = 20,000** visible nodes for "Expand below"/right-click and expand-all.
- Search (Enter jumps + expands + centers first of ≤100 matches, yellow highlight); depth selector (phases/artifacts/tasks); branch filter (All/Inputs/Outputs); tooltip (path, level, children, funnel + critique metadata, atomic ◇); header stats (per-layer counts, **json size**, nodes/funneled/kept/atomic).
- Node ring colors: funnel-processed → white, critiqued → red, selected → blue, search hit → yellow.

## 5. `workflow_showcase.html`

Static visual timeline of the ingest → llm → funnel pipeline (demo/training aid).
